<h1>AI Chat Application</h1>

<p>
A modern, scalable, and high-performance AI chat application built with
<strong>React</strong>, <strong>Vite</strong>, and <strong>TailwindCSS</strong>,
featuring real-time AI interactions powered by <strong>Puter AI</strong>.
</p>

<p>
This project demonstrates professional frontend architecture, clean UI/UX
principles, and production-ready code quality.
</p>

<hr />

<hr />

<h2>🚀 Features</h2>

<ul>
  <li>Real-time AI-powered conversations using Puter AI</li>
  <li>Elegant and responsive UI built with TailwindCSS v4</li>
  <li>Smooth chat bubbles with gradient styling</li>
  <li>Auto-scroll behavior and loading state handling</li>
  <li>Fast and optimized Vite development environment</li>
  <li>Fully responsive design (mobile → large screens)</li>
  <li>Clean and maintainable code structure</li>
</ul>

<hr />

<h2>🛠️ Tech Stack</h2>

<ul>
  <li><strong>React 19</strong> – Component-based UI architecture</li>
  <li><strong>Vite 7</strong> – Lightning-fast development & optimized builds</li>
  <li><strong>TailwindCSS 4</strong> – Modern utility-first styling</li>
  <li><strong>Puter AI</strong> – AI-powered chat engine</li>
  <li><strong>PostCSS & Autoprefixer</strong> – CSS processing</li>
  <li><strong>ESLint</strong> – Code quality and consistency</li>
</ul>

<hr />

<h2>📦 Installation</h2>

<p>Clone the repository and install dependencies:</p>

<pre><code>npm install
npm run dev</code></pre>

<p>Open in browser:</p>

<pre><code>http://localhost:5173</code></pre>

<hr />

<h2>🤖 AI Integration</h2>

<p>Example of AI request handling:</p>

<pre><code>const reply = await window.puter.ai.chat(message);</code></pre>

<p>
The AI integration layer is designed to be easily replaceable with other providers.
</p>
